# 🎓 Student Record Management System

A light-weight Python application designed to store and search student academic records. This project features both a **Command-Line Interface (CLI)** and a **Graphical User Interface (GUI)** using Tkinter.

---

## 🌟 Features

- **CLI Version (`student.py`)**[cite: 1]:
  - Interactive terminal menu for roll number selection[cite: 1].
  - Array-based record processing[cite: 1].
  - Automatic error handling for invalid input/termination[cite: 1].

- **GUI Version (`gui.py`)**[cite: 2]:
  - Built with Python's built-in `tkinter` library[cite: 2].
  - User-friendly interface with styled layout and color-coded feedback[cite: 2].
  - Fast record lookup using Python Dictionaries[cite: 2].
  - Error indicator when a roll number is not found[cite: 2].
